{%- comment -%} Analytics. Two independent, optional tools; each renders ONLY in production (actions/jekyll-build-pages sets JEKYLL_ENV=production) and ONLY when its key in _config.yml is non-empty, so local `jekyll serve` and a half-configured site stay clean. /privacy/ reads the SAME keys, so turning a tool on here turns its disclosure on there in the same commit. 1. Google Analytics 4 — `google_analytics: "G-XXXXXXXXXX"`. Standard gtag.js snippet. GA4 sets first-party cookies (_ga, _ga_*) and anonymises IP addresses by default (there is no anonymize_ip switch in GA4; it is always on). Google Signals / ads personalisation are switched OFF below so the site never contributes to cross-site ad profiles — keep it that way; the privacy page states it as fact. 2. GoatCounter — `goatcounter: "CODE"` (the "CODE" in https://CODE.goatcounter.com). Cookie-free pageview counter, kept as a lightweight cross-check for GA4. {%- endcomment -%} {%- if jekyll.environment == 'production' -%} {%- if site.google_analytics and site.google_analytics != '' -%} {%- endif -%} {%- if site.goatcounter and site.goatcounter != '' -%} {%- endif -%} {%- endif -%}
