{%- comment -%} Analytics. Two independent, optional tools; each renders ONLY in production (actions/jekyll-build-pages sets JEKYLL_ENV=production) and ONLY when its key in _config.yml is non-empty, so local `jekyll serve` and a half-configured site stay clean. /privacy/ reads the SAME keys, so turning a tool on here turns its disclosure on there in the same commit. 1. Google Analytics 4 — `google_analytics: "G-XXXXXXXXXX"`. Standard gtag.js snippet. GA4 sets first-party cookies (_ga, _ga_*) and anonymises IP addresses by default (there is no anonymize_ip switch in GA4; it is always on). Google Signals / ads personalisation are switched OFF below so the site never contributes to cross-site ad profiles — keep it that way; the privacy page states it as fact. 2. GoatCounter — `goatcounter: "CODE"` (the "CODE" in https://CODE.goatcounter.com). Cookie-free pageview counter, kept as a lightweight cross-check for GA4. {%- endcomment -%} {%- if jekyll.environment == 'production' -%} {%- if site.google_analytics and site.google_analytics != '' -%} {%- comment -%} Content tagging: every hit carries content_type (home / post / series_hub / page) and, for a post or series hub, content_series (the series slug, stable) and content_category (its display title). To use them in GA4 reports, register two EVENT-scoped custom dimensions in Admin > Data display > Custom definitions, with exactly these parameter names: content_series, content_category (and content_type if wanted). Not retroactive; reports show them 24-48 h after registration. {%- endcomment -%} {%- assign _series_slug = page.series | default: page.series_slug -%} {%- if page.url == '/' -%}{%- assign _ctype = 'home' -%} {%- elsif page.layout == 'post' -%}{%- assign _ctype = 'post' -%} {%- elsif page.layout == 'series' -%}{%- assign _ctype = 'series_hub' -%} {%- else -%}{%- assign _ctype = 'page' -%}{%- endif -%} {%- if _series_slug -%}{%- assign _series_meta = site.data.series | where: "slug", _series_slug | first -%}{%- endif -%} {%- endif -%} {%- if site.goatcounter and site.goatcounter != '' -%} {%- endif -%} {%- endif -%}
