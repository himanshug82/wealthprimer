{%- comment -%} Applies Indian digit grouping (12,34,567.89) to every table cell whose whole content is a number, so posts can print raw data values in tables ({{ db25.revenue }}) and still follow the style rule in CLAUDE.md. Usage (in a layout): {% include inr-tables.html html=content %} A cell is reformatted only if, after an optional wrapper, it is: optional ₹ / - / − prefix, digits with at most one ".", optional % suffix, and at least 4 digits before the decimal point. Numeric cells written with a hyphen-minus (-2.5%) get a true minus (−2.5%). Anything else — dates (2024-03-28), labels, links, "31 March 2025", numbers that already have commas — passes through untouched. Year guard: a bare 4-digit integer from 1900 to 2099 in the FIRST cell of a row is a year label (the alpha / tracking-error / index-fund tables), not a value, and is left alone. Pure Liquid for the same reason as inr.html: the Pages deploy runs Jekyll in safe mode, so a _plugins/ filter would be silently ignored in production.
