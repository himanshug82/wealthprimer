{%- comment -%} Previous / next post within the same series, in reading (date) order. `site.posts` only contains PUBLISHED posts (future: false), so "next" is naturally absent until the next post's date arrives — which is also why this must never use {% raw %}{% post_url %}{% endraw %} (a forward reference fails the whole build; see the build rule in TODO.md). When there is no next post but the series plans more, say so rather than leaving the reader at a dead end. Sets `series_meta`, `series_index` (1-based), `series_total` for post.html's header line too, so the two never disagree; include this ONCE before the header with `header=true` to compute, then again in the body to render. {%- endcomment -%} {%- assign series_meta = site.data.series | where: "slug", page.series | first -%} {%- assign in_series = site.posts | where: "series", page.series | sort: "date" -%} {%- assign series_index = 0 -%} {%- for p in in_series -%} {%- if p.url == page.url -%}{%- assign series_index = forloop.index -%}{%- endif -%} {%- endfor -%} {%- assign series_total = in_series.size -%} {%- if series_meta.planned and series_meta.planned > series_total -%} {%- assign series_total = series_meta.planned -%} {%- endif -%} {%- assign prev_i = series_index | minus: 2 -%} {%- assign next_i = series_index -%} {%- assign prev_post = nil -%}{%- assign next_post = nil -%} {%- if series_index > 1 -%}{%- assign prev_post = in_series[prev_i] -%}{%- endif -%} {%- if series_index < in_series.size -%}{%- assign next_post = in_series[next_i] -%}{%- endif -%} {%- unless include.header -%} {%- if series_meta and series_index > 0 -%}
