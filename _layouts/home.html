--- layout: default --- {%- comment -%} Overrides minima's home layout, which was a bare reverse-chronological list of every post title. Two problems that fixed: a first-time reader landed on whatever ratio happened to publish last (with no way to tell that it was post 21 of a 33-part series), and minima's `show_excerpts` silently rendered NOTHING, because 68 of 69 posts open with a {% raw %}{% assign %}{% endraw %} block — which is what Jekyll took as the first paragraph, and it renders to an empty string. Rather than fight the auto-excerpt, this layout uses each post's explicit `description:` front matter, which is the same one-line summary that feeds the meta description and the RSS summary. One sentence per post, written once, used in three places. {%- endcomment -%}
